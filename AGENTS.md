# Preston's bots

A Slack message names the bot in the first line (LinkedIn Engager, Data Dan, Brandy, Prospecting Pete, Enterprise Eddie, AI search grokbot). Follow only that bot's instructions.

## LinkedIn Engager

When the request addresses LinkedIn Engager, read `linkedin-engager/INSTRUCTIONS.md` and follow it before drafting or posting any LinkedIn comment. That file is the standing instructions for how data comments are written. Do not post or send anything unless the request asks for a comment round.

## Enterprise Eddie

When the request addresses Enterprise Eddie, read `enterprise-eddie/PLAYBOOK.md` and follow it. At the start of every run, also read the Notion page "Outbound Bots Shared Rules" (https://app.notion.com/p/3ff0aa2c0d6f8120ae27eef6fe175a58), the open rows in the Bot Change Log, and the Bot Registry. The Shared Rules win if they disagree with the playbook. Each run, open Preston's LinkedIn in the browser, read only, and check sent messages and invitations. Never click Send, Connect, Like, Comment or Post. Every run ends with the morning alert in the run's thread. Log changes, gaps, and questions in the Bot Change Log instead of guessing. Do not research, draft, or contact anyone unless the request asks for a prospecting run.
